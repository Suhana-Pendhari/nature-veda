🌿 NatureVeda
“Herbal solutions for everyday health.”
________________________________________
🧾 Project Summary
NatureVeda is a full-stack web application that provides users with natural remedies and medicinal plant information for everyday health problems. The platform allows users to search for common issues like cough, skin problems, or hair care and get safe, home-based herbal solutions using easily available ingredients.
In addition to remedies, the website includes a medicinal plants section, where users can explore the uses, benefits, and applications of various plants like tulsi, aloe vera, and neem. The system also supports user authentication, enabling users to register, log in, and save their favorite remedies for future reference.
An admin panel is included to manage the content of the website, allowing the admin to add, update, or delete remedies and plant information. The website also features a theme toggle (light/dark mode) to enhance user experience.
Overall, NatureVeda is designed as a user-friendly, informative, and practical platform that combines traditional herbal knowledge with modern web technology.
